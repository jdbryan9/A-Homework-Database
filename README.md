# Homework Assignment Database

A simple relational homework tracker built with Python's built-in `sqlite3` + `http.server`.

## Features

- Relational SQLite table for assignments.
- Add and delete assignments from a polished web UI.
- Tracks title, course, due date, and notes.
- Shows a ⚠️ icon for assignments due within 3 days.
- Pre-loaded sample data on first run.

## Run locally

```bash
python3 app.py
```

Then open <http://localhost:8000>.
